# MSc Research - Embedded Artificial Intelligence

## Overview
Repository for MSc research focusing on embedded AI model development, quantization, and edge deployment.

## Repository Structure
- `data/`: Raw and processed datasets (git-ignored)
- `notebooks/`: Exploratory analysis and experimentation
- `src/`: Reusable Python modules and source code
- `models/`: Model checkpoints and quantized binaries
- `docs/`: Technical reports and documentation
- `outputs/`: Plots, logs, and evaluation metrics
